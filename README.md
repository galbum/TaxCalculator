# TaxCalculator

A tax calculator project. Sibling to `FundemntalAnalysis`.

## Status

Freshly scaffolded — ready for implementation. The intended scope is a tool that
computes tax liabilities given income, deductions, and filing parameters.

## Getting started

```bash

python3 -m venv .venv
source .venv/bin/activate
# pip install -r requirements.txt   # once dependencies are added
```
